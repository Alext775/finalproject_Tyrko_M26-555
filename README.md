
# ValutaTrade Hub

ValutaTrade Hub — консольное приложение на Python для симуляции торговли фиатными и криптовалютами.

Программа позволяет регистрировать пользователей, создавать валютные кошельки, покупать и продавать валюту, получать обменные курсы и отслеживать их изменения.

Все сделки выполняются с виртуальными средствами.

## Технологии

- Python 3.11+
- uv — управление проектом и зависимостями
- Ruff — проверка и форматирование кода
- PrettyTable — таблицы в консоли
- Requests — HTTP-запросы
- JSON — локальное хранение данных
- unittest — автоматические тесты

## API-ключ

Для получения фиатных курсов используется ExchangeRate-API.

При первом запуске программа предлагает ввести API-ключ.

Получить его можно здесь:

https://www.exchangerate-api.com/

После ввода ключ сохраняется в:

```text
.secrets/credentials.json
```

Папка `.secrets/` исключена из Git.

Для замены ключа используется команда:

```text
set-api-key
```

Если при повторном вводе нажать Enter, сохраненный ключ остается без изменений.

CoinGecko используется для криптовалют без API-ключа.

## Автоматическое обновление

При запуске приложение сразу пытается получить новые курсы.

Во время работы программы фоновый планировщик периодически обновляет курсы.

Интервал задается в `pyproject.toml`:

```toml
[tool.valutatrade]
rates_ttl_seconds = 60
```

По умолчанию в данной конфигурации обновление выполняется каждые 60 секунд.

Планировщик работает внутри приложения и не требует отдельного терминала.

При завершении приложения фоновый поток останавливается.

## Кеш и история курсов

Используются четыре JSON-файла:

- `data/users.json` — пользователи
- `data/portfolios.json` — портфели
- `data/rates.json` — последние курсы
- `data/exchange_rates.json` — история измерений

Отсутствующие JSON-файлы создаются при первом запуске.

Курс считается актуальным, пока его возраст не превышает TTL.

Если курс устарел, приложение сообщает об этом и предлагает выполнить `update-rates`.

История сохраняется с уникальными идентификаторами пары и времени измерения.

Для записи JSON используется временный файл и атомарная замена.

## Обработка ошибок

Приложение обрабатывает:

- Неверные аргументы команд
- Повторную регистрацию пользователя
- Неправильный пароль
- Недостаток средств
- Неизвестную валюту
- Устаревший курс
- Ошибки HTTP и недоступность API
- Некорректный ответ внешнего API
- Поврежденные JSON-файлы

## Ограничения

- Торговля выполняется только виртуальными средствами
- Используется локальное JSON-хранилище
- Для финансовых расчетов применяется float в соответствии с учебным ТЗ
- SHA-256 с индивидуальной солью используется как учебный механизм хранения пароля
- Для реального финансового приложения потребовались бы Decimal, полноценная база данных и более специализированное хеширование паролей
